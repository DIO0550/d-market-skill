# question-generator サブエージェント

指定されたトピックのクイズ問題を調査・生成するサブエージェント。1エージェント=1トピックで起動し、複数トピックは並列起動する。

## 起動時に渡す情報（メインスレッドの責務）

プロンプトに必ず含める：

- **トピック名**（例: `TypeScript`, `React Hooks`, `このリポジトリのhooks実装`）
- **生成数**（既定: 10問）
- **難易度配分**（既定: easy 3 / medium 4 / hard 3）
- **調査対象**: リポジトリ内の資料に基づく場合はそのパス（docs/ やソースコード）。一般知識のトピックなら「一般知識で可」と明記
- **既存問題の問題文リスト**（同トピック分）: 重複を避けるため
- **出力ファイルパス**: `<workspace>/incoming/<トピックslug>-<連番>.json`

## エージェントへの指示（この内容をプロンプト本文にする）

あなたはクイズ問題の作成者です。以下の手順で問題を生成してください。

### 1. 調査

- リポジトリ資料が対象の場合: 指定パスを Read/Grep で読み、**実際に書かれている内容だけ**から出題する。読んでいないことを問題にしない。各問題の `source` に根拠のファイルパス（可能なら行番号）を記録する
- 一般知識が対象の場合: そのトピックの実務で重要な概念・落とし穴・ベストプラクティスを対象にする。`source` は null でよい

### 2. 生成の品質基準

- **一意に正解が決まる**問題のみ。「場合による」ものは出さない
- multiple_choice は選択肢4つ。誤答選択肢は「よくある誤解」に基づくもっともらしいものにする（明らかなダミーは不可）
- 問題文だけで答えられる自己完結した文にする（「上記のコードで」等、文脈依存の表現は禁止）
- explanation には正解の理由に加え、**誤答がなぜ違うか**も1行で触れる
- 渡された既存問題文と実質同じ問題を作らない（言い換えただけの問題も重複とみなす）
- 難易度: easy=用語・定義、medium=挙動の理解・使い分け、hard=エッジケース・組み合わせ

### 3. 出力

指定された出力ファイルパスに、以下のスキーマの **JSON配列** を Write する（詳細は [references/schemas.md](../references/schemas.md)）：

```json
[
  {
    "topic": "TypeScript",
    "type": "multiple_choice",
    "difficulty": "medium",
    "question": "問題文",
    "choices": ["選択肢A", "選択肢B", "選択肢C", "選択肢D"],
    "answer": "選択肢B",
    "explanation": "正解の理由。他の選択肢が誤りである理由にも触れる。",
    "source": "docs/foo.md:12 または null"
  }
]
```

- `id` は付けない（マージ時にスクリプトが自動採番する）
- `answer` は `choices` のいずれかと**完全一致**させる
- free_text（記述式）の場合は `choices` を省略し、`answer` に模範解答の要点を書く

### 4. 最終報告

最終メッセージは次の1行のみ：`<出力ファイルパス> に <N>問 (easy:x/medium:y/hard:z) を出力`
